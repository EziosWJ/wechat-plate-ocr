# 实现说明

## 数据流程

```text
后置摄像头拍照
  → 卸载摄像头预览
  → Canvas 解码照片并处理可判断的方向
  → 按轮次选择裁剪区域，读取 RGBA 像素
  → VisionKit 静态 OCR
  → 记录原始文字与坐标
  → 号码规范化、候选提取和人工核对建议
  → 用户确认后回填当前页输入框
```

拍摄与识别分阶段占用资源，降低相机组件与 VisionKit 同时运行时的资源冲突。

## VisionKit 服务

`miniprogram/services/vision-ocr.ts` 封装 `VisionOcrService`：

- `recognize(input)`：输入临时照片路径、预览尺寸、参考框区域与可选旋转角度，返回原始文字、有效格式候选、人工核对建议及耗时。
- `cancel()`：取消当前任务，清理定时器、事件监听、解码图片和原生会话。
- `onPreview`：报告照片尺寸和本轮裁剪区域。
- `onPixels`：返回送入 OCR 的 RGBA 像素副本，用于页面绘制真实输入预览。
- `onDebug`：报告轮次、相对时间、阶段、说明与详细数据；console 日志独立于该回调，始终打印。

会话采用 `wx.createVKSession({ track: { OCR: { mode: 2 } }, version: 'v1' })`。传给 `runOCR` 的数据包含 `frameBuffer`、`width`、`height`，结果通过 `addAnchors` 和 `updateAnchors` 收集。

官方类型中的 `Track` 将 `plane` 声明为必填；本项目仅在 OCR-only 配置处使用类型断言，保持与官方 OCR 示例的配置一致，不额外启用平面识别。

## 裁剪与可调参数

| 参数 | 当前值 | 位置 |
| --- | --- | --- |
| 参考框宽度 | 预览宽度的 64% | `pages/index/index.wxss` 的 `.finder` |
| 参考框高度 | 200rpx | 同上 |
| 第一轮框外余量 | 左右各 10%，上下各 30% | `services/vision-ocr.ts` 的 `attempts` |
| 第二轮框外余量 | 左右各 35%，上下各 65% | 同上 |
| 第三轮 | 全图 | 同上 |
| 输入最长边 | 1600px，不放大小图 | 图像缩放逻辑 |
| 每轮等待上限 | 8000ms，包括解码和初始化 | `deadline` |
| 有效候选提前结束 | 提交后至少 1200ms，文字变化后至少静默 800ms | `settleTimer` |
| 相机启动 / 拍照上限 | 各 10000ms | `pages/index/index.ts` |

余量以参考框尺寸为基数，每侧分别增加，最终限制在图像范围内。`utils/crop.ts` 支持统一余量数值或 `{ horizontal, vertical }` 两个独立比例。

取景框用于指引大致位置，不负责检测真实车牌边界。本项目没有独立的车牌检测或透视矫正模型。修改 CSS 框大小后，页面会查询其实际位置和尺寸，无需另外硬编码裁剪框坐标。

仅当解码尺寸与原始尺寸相同、宽高不相等，且元信息为 EXIF `left` / `right` 时，自动进行相应的四分之一圈旋转。其他情况保留解码方向。手动旋转会绕过旧的取景坐标，直接对旋转后的全图识别。

## 号码提取

`utils/plate.ts` 提供以下纯函数：

- `normalizePlate`：统一全角/半角与大小写，清理空格和常见分隔符。
- `isValidPlate`：校验大陆普通七位及新能源八位号码结构。
- `analyzePlateCandidates`：输出有效格式候选、人工核对建议，以及每个文本的接受/拒绝原因。
- `extractPlateCandidates`：只返回有效格式候选的简化入口。

分片只在坐标有效、处于同一行且相邻时拼接。已完整的号码遇到旁边车型文字时停止扩展；如果七位片段与相邻一位能组成有效新能源八位号码，则优先八位。

缺少坐标时，不把不同文字框直接拼成有效格式候选；恰好两个框构成明确的省份/机关前缀和号码后缀时，单独提供人工核对建议。`O/0`、`I/1` 不自动替换。

“候选有效”只表示符合本项目号码规则，不表示已经验证号码真实存在或 OCR 每位正确。

## 生命周期与数据

每次拍照/识别具有任务序号。重拍、取消、切后台后，旧回调不能再更新新页面结果。每轮重试使用独立 VisionKit 会话，避免上一轮结果混入下一轮。

有效格式候选稳定后可以提前结束。空数组、部分文字和无效文字不会触发短时间提前结束；达到本轮上限时保留原文，再决定是否进入下一轮。初始化阶段一直没有成功提交图片时，返回明确超时错误。

页面临时持有拍照文件路径、实际输入像素与调试事件。原图在确认、重拍、取消、隐藏或退出时尝试删除；像素缓存随页面流程清理。应用代码不调用照片上传、云 OCR、登录或车牌记录存储接口。console 中已打印的内容由调试工具管理，不受页面内存清理控制。
